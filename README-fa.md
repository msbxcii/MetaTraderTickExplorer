# متاتریدر تیک اکسپلورر

[English](README.md) | فارسی

**متاتریدر تیک اکسپلورر** (`mt-tick.explorer`) یک اپلیکیشن ویندوزی است که داده‌های تیک را از ترمینال لوکال متاتریدر ۵ روی سیستم شما استخراج می‌کند و از آن برای ساختن کندل‌های ثانیه‌ای (و بالاتر) استفاده می‌کند. داده‌ها مستقیماً روی دیسک ذخیره می‌شوند و امکان استفاده از چارت با دقت ثانیه، هم در لایو بازار و هم برای هر تاریخی از گذشته، فراهم می‌شود. نمودارها با کتابخانه‌ی متن‌باز رسمی [TradingView Lightweight Charts™](https://www.tradingview.com/lightweight-charts/) نمایش داده می‌شوند.

> **این پروژه هیچ ارتباط رسمی با شرکت MetaQuotes ندارد و مورد تأیید آن نیست.** بخش [علائم تجاری](#علائم-تجاری) را ببینید.

## 🆓 اطلاعیه‌ی رسمی توزیع و هشدار کلاهبرداری

**متاتریدر تیک اکسپلورر کاملاً رایگان است و همیشه رایگان خواهد ماند.** این برنامه به‌عنوان نرم‌افزار متن‌باز تحت لایسنس Apache 2.0 توسط سازنده‌ی اصلی آن، Msbxcii، منتشر شده است.

- **تنها** منبع رسمی همین ریپازیتوری است: <https://github.com/msbxcii/MetaTraderTickExplorer>. نسخه‌های رسمی **فقط** در بخش [Releases](https://github.com/msbxcii/MetaTraderTickExplorer/releases) منتشر می‌شوند.
- پروژه‌ی رسمی **هرگز** بابت دانلود، لایسنس، کد فعال‌سازی، امکانات «ویژه»، اشتراک یا پشتیبانی هزینه‌ای دریافت نمی‌کند و **هیچ** کانال تلگرام رسمی، نماینده‌ی فروش یا توزیع‌کننده‌ی پولی ندارد.
- **اگر برای این برنامه یا هر یک از امکانات آن از شما پول خواسته شده، کلاهبرداری است.** درخواست بازگشت وجه کنید، فروشنده را گزارش دهید و با [ثبت Issue](https://github.com/msbxcii/MetaTraderTickExplorer/issues) به کاربران دیگر هشدار دهید.
- نسخه‌هایی که از منابع دیگر دریافت می‌شوند ممکن است دست‌کاری شده باشند و بدافزار داشته باشند. فقط نسخه‌هایی را اجرا کنید که از بخش Releases رسمی دانلود کرده‌اید یا خودتان از روی همین سورس ساخته‌اید.

فورک کردن طبق شرایط لایسنس آزاد است (بخش [فورک و برندینگ](#فورک-و-برندینگ))، اما فورک‌ها نباید به‌عنوان نسخه‌ی رسمی معرفی شوند.

## 🔒 امنیت و حریم خصوصی

- **فقط ترمینال لوکال:** تمام داده‌های بازار و معاملات فقط از طریق **ترمینال محلی متاتریدر** (پکیج رسمی MetaTrader 5 برای Python) انجام می‌شود. هیچ داده‌ای به سرویس شخص ثالث ارسال نمی‌شود و نیازی به سرور خارجی نیست.
- **تنها استثنا، بررسی آپدیت:** گزینه‌ی Check for Update فقط یک درخواست ساده (فقط‌خواندنی) به API عمومی GitHub می‌فرستد تا ببیند نسخه‌ی جدیدی منتشر شده یا نه. هیچ اطلاعات شخصی، اطلاعات حساب یا داده‌ی بازار ارسال نمی‌شود. در صورت دانلود آپدیت، فایل EXE جدید از بخش Releases پروژه در GitHub دریافت می‌شود.
- **بدون دسترسی به اطلاعات حساب:** نیازی به نام کاربری، رمز عبور یا اطلاعات ورود نیست؛ این اطلاعات فقط در خود ترمینال می‌ماند.
- **داده‌ها محلی هستند:** تمام داده‌های تیک/کندل و تنظیمات فقط روی سیستم خودتان ذخیره می‌شوند.

## 💾 محل ذخیره‌ی داده‌ها و لاگ‌ها

- **اجرا از سورس (`run_chart.cmd`، دولوپرها):**
  ```text
  <repository-folder>\output\
  <repository-folder>\logs\
  ```

- **اجرا از فایل `.exe`:** برای پورتابل ماندن EXE (دسکتاپ، فلش یا هر مسیر دیگر)، داده‌ها و لاگ‌ها کنار خود EXE ذخیره نمی‌شوند و در AppData کاربر ویندوز نوشته می‌شوند:
  ```text
  %LOCALAPPDATA%\MT-TickExplorer\output\
  %LOCALAPPDATA%\MT-TickExplorer\logs\
  ```
  (معمولاً معادل `C:\Users\<username>\AppData\Local\MT-TickExplorer\`.)

## شروع کار

### کاربران عادی

آخرین فایل `mt-tick.explorer-<version>.exe` را از بخش [Releases](https://github.com/msbxcii/MetaTraderTickExplorer/releases) دانلود و اجرا کنید. نیازی به Python یا تنظیمات دیگری نیست. در اولین اجرا، ویزارد **Get Started** این مراحل را طی می‌کند:

1. **آماده‌سازی متاتریدر:** بررسی فعال بودن Python Integration و لاگین بودن ترمینال.
2. **پوشه‌ی اصلی پروژه (Root Project Folder):** انتخاب محل ذخیره‌ی داده‌ها و تنظیمات.
3. **انتخاب نماد:** انتخاب یک نماد از لیست بروکر؛ برنامه ۳ روز اخیر داده‌ی تیک آن را دانلود می‌کند (بعداً قابل افزایش است).
4. **پایان:** پنجره‌ی چارت باز می‌شود.

> ممکن است Windows SmartScreen درباره‌ی EXE بدون امضا هشدار دهد. اگر تردید دارید، خودتان از روی سورس Build بگیرید.

### دولوپرها

نیاز به Python 3.12 (۶۴ بیتی، هم‌بیت با ترمینال متاتریدر ۵).

```bash
git clone https://github.com/msbxcii/MetaTraderTickExplorer.git
cd MetaTraderTickExplorer
pip install -r requirements.txt
run_chart.cmd
```

## ساخت نسخه‌ی Release (EXE)

پروژه شامل تعریف Build قابل تکرار PyInstaller (`MetaTraderTickExplorer.spec`) و فایل `build.cmd` است:

```cmd
pip install -r requirements.txt -r requirements-dev.txt
build.cmd
```

نام فایل خروجی از `src/version.py` (`APP_NAME` + `VERSION`) ساخته می‌شود:

```text
dist\mt-tick.explorer-v3.0.0.exe
```

برای انتشار نسخه‌ی جدید فقط `VERSION` را در `src/version.py` تغییر دهید؛ عنوان پنجره، خروجی Build و بررسی آپدیت همه از همان‌جا خوانده می‌شوند. کامیت Release را با همان رشته تگ کنید (مثلاً `git tag v3.0.0`).

## فورک و برندینگ

طبق لایسنس Apache 2.0 می‌توانید پروژه را فورک کنید و نسخه‌ی خودتان را بسازید. اگر نسخه‌ی خودتان را منتشر می‌کنید:

1. **آیکون را عوض کنید:** آیکون خودتان را در `assets\Icon.ico` (و `web/assets/icon.svg`) قرار دهید.
2. **آدرس Check for Update را به ریپوی خودتان تغییر دهید:** مقدار `GITHUB_REPO` در `src/update_checker.py` را به `owner/repo` خودتان تغییر دهید. در غیر این صورت به کاربران شما نسخه‌های پروژه‌ی اصلی پیشنهاد می‌شود.
3. **اطلاعیه‌ی رسمی را به‌روز کنید:** مقادیر `OFFICIAL_REPO_URL` و `FREE_NOTICE` در `src/version.py` و متن اطلاعیه در `web/get-started.html` و `web/About.md` را به پروژه‌ی خودتان تغییر دهید.
4. **از نام خودتان استفاده کنید:** فورک خود را به‌عنوان نسخه‌ی رسمی *MetaTrader Tick Explorer* / `mt-tick.explorer` معرفی نکنید و `APP_NAME` را در `src/version.py` تغییر دهید. طبق لایسنس، اطلاعیه‌ی کپی‌رایت اصلی و فایل [NOTICE](NOTICE) را حفظ کنید.

## 📊 نحوه‌ی استفاده

📘 **آموزش کامل قدم‌به‌قدم: [docs/TUTORIAL-fa.md](docs/TUTORIAL-fa.md)**

- **معامله:** **کلیک وسط ماوس** = سفارش مارکت، **Shift + کلیک وسط** = سفارش پندینگ (قابل تغییر از **Settings → Keyboard Shortcuts**).

- **بارگذاری اولیه:** برای هر نماد جدید فقط **۳ روز اخیر** داده‌ی تیک دریافت می‌شود تا چارت سریع آماده شود.
- **تاریخچه‌ی بیشتر:** در پنجره‌ی **Market Data Overview** با **Extend** داده‌های قدیمی‌تر را تا تاریخ هدف دریافت کنید (یا **Backfill** برای بازه‌ی پیش‌فرض). این کار در پس‌زمینه انجام می‌شود.
- **پرش به هر زمان:** با کلید **SPACE** پنجره‌ی **Jump Time** باز می‌شود و می‌توانید به هر تاریخ/ساعتی بروید، در Live یا Replay.
- **شورتکات‌ها** (قابل تغییر از **Settings → Keyboard Shortcuts**): پرش به جدیدترین/قدیمی‌ترین کندل، آندو/پاک‌کردن ترسیم‌ها و کلیدهای سریع ابزارهای ترسیم (خط روند، خط افقی/عمودی، مستطیل، فیبوناچی).
