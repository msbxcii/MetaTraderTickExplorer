# MetaTrader Tick Explorer


برنامه "متاتریدر تیک اکسپلورر" یک اپلیکیشن ویندوزی است که داده های تیک را از طریق ترمینال لوکال متاتریدر در سیستم استخراج میکند و سپس از آن برای ساختن کندل های ثانیه (و بالاتر) استفاده میکند.این داده ها مستقیما در دیسک ذخیره میشوند و به کاربر امکان استفاده از چارت با دقت ثانیه در لایو بازار و همچنین هر تاریخی از گذشته را فراهم میکند. داده های بدست آمده از طریق پروژه متن باز رسمی [تریدینگ ویو Lightweight chart ](https://www.tradingview.com/lightweight-charts/)اجرا میشوند. 

### از جمله قابلیت های این نرم افزار:

1) مشاهده چارت در حالت **Replay Mode** با سرعت واقعی لایو بازار (1 تیک در ثانیه ) که به کاربر امکان شبیه سازی واقع گرایانه برای تمرین را میدهد.
2) امکان استفاده از حالت **مولتی چارت** برای مشاهده نمودار در چندین تایم فریم مختلف زمانی که از آن میتوان هم در حالت Live و هم در حالت Replay بهره برد.
3) اجرای کاملا **آفلاین** برنامه براساس دیتابیس ذخیره شده برای تمرین بر روی داده های گذشته
4) (در آینده) اجرای مستقیم معاملات در داخل برنامه

### امنیت و نحوه ارتباط برنامه

این برنامه برای دریافت داده‌های تیک **به هیچ سرور خارجی یا سرویس شخص ثالثی متصل نمی‌شود** و ارتباط آن صرفاً با **ترمینال MetaTrader** انجام می‌گیرد. داده‌ها از طریق **API رسمی MetaTrader برای Python** دریافت و پردازش می‌شوند.

برنامه **نیازی به دریافت، ذخیره یا ارسال نام کاربری و رمز عبور حساب معاملاتی ندارد** و اطلاعات ورود به حساب صرفاً در اختیار ترمینال MetaTrader باقی می‌ماند.

بنابراین، داده‌های تیک مستقیماً از ترمینال MetaTrader دریافت شده و برای دریافت و پردازش آن‌ها **هیچ سرور یا واسطه خارجی مورد نیاز نیست**.

## شروع کار

### کاربران عادی

آخرین فایل `.exe` را از بخش **Releases** پروژه دانلود و اجرا کنید — نیازی
به Python یا هیچ تنظیم دیگری نیست. در اولین اجرا، مراحل زیر طی می‌شود:
### دولوپرها

```bash
git clone <repository-url>
cd <repository-folder>
pip install -r requirements.txt
run_chart.cmd
```

## ساخت نسخه Release با EXE

پروژه برای ساخت نسخه ویندوزی، تنظیمات استاندارد PyInstaller و فایل
`build.cmd` را دارد :

 در محیط ویندوز که Python و PyInstaller در آن نصب است، اجرا کنید:

```cmd
build.cmd
```

فایل نهایی در مسیر زیر ساخته می‌شود:

```text
dist\MetaTrader Tick Explorer.exe
```

این Build به صورت **one-file** و **windowed/no-console** ساخته می‌شود؛ بنابراین
کاربر نهایی هنگام اجرای EXE پنجره CMD جداگانه نخواهد دید و نیازی به نصب Python
ندارد. فایل `run_chart.cmd` همچنان برای اجرای نسخه سورس توسط Developer باقی
می‌ماند.

برای GitHub Releases، تگ Release را مطابق مقدار `VERSION` در فایل
`src/version.py` قرار دهید (در این نسخه `V68`) و فایل EXE ساخته‌شده از `dist/`
را به Release اضافه کنید.
