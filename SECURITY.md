# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please **do not** open a public issue. Report privately via GitHub's
[Report a vulnerability](https://github.com/msbxcii/MetaTraderTickExplorer/security/advisories/new) (Security tab).

Include a description, steps to reproduce and the affected version. You will get a response as soon as possible.

## Scope notes
- The app only talks to the local MetaTrader terminal, plus one read-only request to the GitHub API for update checks.
- Only download official builds from the project's [Releases](https://github.com/msbxcii/MetaTraderTickExplorer/releases) page.
